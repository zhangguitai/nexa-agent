# 演示视频材料说明

| 文件 | 说明 |
| --- | --- |
| `NEXA-Agent-Workspace-演示视频-字幕版.mp4` | 1920 × 1080、30 FPS、7 分 20 秒，已烧录中文字幕 |
| `NEXA-Agent-Workspace-演示字幕.srt` | 可单独导入剪辑软件的字幕文件 |
| `NEXA-Agent-Workspace-配音稿.txt` | 与实际段落时间轴对应的普通话配音稿 |

当前 MP4 的音频轨为静音，原因是自动化环境禁止调用系统语音引擎。正式提交前请按配音稿录制普通话讲解，将音轨与段落时间轴对齐后重新导出 MP4。

推荐导出参数：

- 容器：MP4
- 视频：H.264，1920 × 1080，30 FPS
- 音频：AAC，44.1 kHz，立体声，128 至 192 kbps
- 时长：5 至 8 分钟
