# 在线部署指南

## 一、部署目标

提供评审期间可公网访问的 NEXA Agent Workspace。在线演示为可选加分项，不配置模型 Key 时仍可使用本地演示模式。

## 二、Docker 部署

项目已提供 `Dockerfile`。

构建：

```bash
docker build -t nexa-agent-workspace .
```

运行：

```bash
docker run -d \
  --name nexa-agent \
  -p 4173:4173 \
  -e LLM_BASE_URL="https://api.deepseek.com/v1" \
  -e LLM_MODEL="deepseek-chat" \
  -e LLM_API_KEY="your_api_key" \
  nexa-agent-workspace
```

健康检查：

```bash
curl http://127.0.0.1:4173/api/health
```

## 三、Render 部署

1. 连接 GitHub / Gitee 仓库。
2. Runtime 选择 Docker。
3. 暴露端口 4173。
4. 添加环境变量。
5. 部署后访问公网 HTTPS 地址。

## 四、Railway 部署

1. 从 GitHub 导入仓库。
2. 启动命令：`node server.mjs`。
3. 设置 `PORT=4173` 和模型环境变量。
4. 生成公网域名。
5. 将域名写入 README 和提交材料。

## 五、云服务器部署

```bash
git clone <仓库地址>
cd <项目目录>
cp .env.example .env
vi .env
npm run dev
```

生产环境建议使用 PM2：

```bash
npm install -g pm2
pm2 start server.mjs --name nexa-agent
pm2 save
```

再通过 Nginx 反向代理到 4173 端口，并配置 HTTPS。

## 六、评审访问检查

- 公网地址可匿名访问。
- 健康检查返回 `ok: true`。
- 页面可在手机和桌面打开。
- 不暴露 `.env`。
- 评审期间服务保持运行。
- 如配置评审账号，将账号写入提交说明。
