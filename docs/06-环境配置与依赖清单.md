# 环境配置与依赖清单

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| Node.js | 20 或更高版本 |
| npm | 随 Node.js 安装，可选 |
| 操作系统 | Windows、Linux 或 macOS |
| 浏览器 | Chrome、Edge、Firefox 或 Safari 近两年版本 |
| 网络 | 真实模型模式需要访问模型接口；本地演示模式无需外网 |

核心项目没有 npm 第三方依赖，不需要执行 `npm install`，也没有前端构建步骤。

## 二、依赖清单

| 文件 | 作用 | 是否运行必需 |
| --- | --- | --- |
| `package.json` | 声明 Node.js 版本要求、启动、检查和测试命令 | 是 |
| `.env.example` | 模型接口与端口的环境变量模板 | 是 |
| `requirements-dev.txt` | Playwright、PDF 和视频材料生成工具 | 否 |
| `Dockerfile` | Node.js 24 Alpine 容器运行环境 | 部署时使用 |
| `.editorconfig` | UTF-8、LF、缩进和行尾空格约定 | 否 |

核心项目只使用 Node.js 内置模块。`requirements-dev.txt` 中的 Python 包用于浏览器验收、PDF 检查或视频材料生成，不参与日常启动。

## 三、环境变量

复制模板：

```bash
cp .env.example .env
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

填写：

```dotenv
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=your_api_key
PORT=4173
```

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `LLM_BASE_URL` | 真实模型模式必填 | OpenAI 兼容接口根地址，不包含 `/chat/completions` |
| `LLM_MODEL` | 真实模型模式必填 | 模型名称，例如 `deepseek-chat`、`gpt-4.1-mini` |
| `LLM_API_KEY` | 真实模型模式必填 | 模型服务密钥，只存在服务端 |
| `PORT` | 否 | 默认 4173 |

未填写 `LLM_API_KEY` 时自动进入本地演示模式。

## 四、启动

```bash
npm run dev
```

访问 <http://localhost:4173>。

健康检查：

```bash
curl http://localhost:4173/api/health
```

## 五、可选开发依赖

`requirements-dev.txt` 用于运行浏览器验收和重新生成 PDF、视频等材料。普通用户运行项目不需要安装。

```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
```

如果本机已安装 Edge，可设置：

```dotenv
BROWSER_PATH=C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

## 六、验收命令

```bash
npm run lint
npm run check
python tests/visual_check.py
```

`npm run lint` 检查文本编码、LF 换行、缩进、行尾空格、调试语句和文件末尾换行；`npm run check` 在此基础上检查 `server.mjs`、`assets/app.js`、`assets/icons.js` 和代码规范脚本的 JavaScript 语法。

重新生成技术文档：

```bash
python tools/build_technical_pdf.py
```

重新生成视频：

```bash
python tools/capture_video_assets.py
python tools/build_demo_video.py
```

## 七、Docker 环境

```bash
docker build -t nexa-agent-workspace .
docker run -d --name nexa-agent -p 4173:4173 nexa-agent-workspace
```

使用环境变量启动：

```bash
docker run -d \
  --name nexa-agent \
  -p 4173:4173 \
  -e LLM_BASE_URL="https://api.deepseek.com/v1" \
  -e LLM_MODEL="deepseek-chat" \
  -e LLM_API_KEY="your_api_key" \
  nexa-agent-workspace
```

## 八、敏感信息规范

- `.env` 已加入 `.gitignore`。
- `.env.example` 只保留空 Key。
- 不得将 API Key、访问令牌、Cookie 或企业凭据提交到公开仓库。
- 如 Key 曾进入 Git 历史，应立即吊销并重新生成。
