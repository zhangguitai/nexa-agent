## 二、推荐仓库设置

### GitHub

1. 创建 Public 仓库。
2. 推送 `main` 分支。
3. 在 `Settings → Actions → General` 允许运行工作流。
4. 确认 Actions 的 `Project Check` 通过。
5. 如需评审访问，可邀请组委会账号为只读协作者。

### Gitee

1. 创建公开仓库。
2. 推送 `main` 分支。
3. 开启 Gitee Go 或使用本地 `npm run check`。
4. 在提交材料中填写仓库公开地址。

## 三、推送步骤

```bash
git init
git add .
git commit -m "feat: complete NEXA agent workspace"
git branch -M main
git remote add origin <仓库地址>
git push -u origin main
```

当前工作区已整理为多个有意义的提交，保留项目初始化、前端产品实现、Agent 服务端、测试与提交材料等开发过程。

## 四、仓库检查

```bash
git status
git log --oneline --decorate --graph
```

确认：

- 没有未提交修改。
- 没有 `.env` 或密钥。
- `README.md` 包含团队信息。
- 仓库可公开访问。
- `screenshots/`、`docs/`、`output/` 已提交。
