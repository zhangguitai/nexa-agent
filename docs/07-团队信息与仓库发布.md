## 二、推荐仓库设置

### GitHub

1. 创建 Public 仓库。
2. 推送 `main` 分支。
3. 在 `Settings → Actions → General` 允许运行工作流。
4. 确认 Actions 的 `Project Check` 通过。
5. 如需评审访问，可邀请组委会账号为只读协作者。

仓库地址：<https://github.com/zhangguitai/nexa-agent>

### Gitee

1. 创建公开仓库。
2. 推送 `main` 分支。
3. 开启 Gitee Go 或使用本地 `npm run check`。
4. 在提交材料中填写仓库公开地址。

## 三、推送步骤

首次关联远程仓库：

```bash
git remote add origin https://github.com/zhangguitai/nexa-agent.git
git branch -M main
git push -u origin main
```

如果已经配置 `origin`，使用：

```bash
git remote set-url origin https://github.com/zhangguitai/nexa-agent.git
git push -u origin main
```

检查远程地址：

```bash
git remote -v
```

当前工作区保留项目初始化、前端产品实现、Agent 服务端、测试、提交材料和本次完善过程的多个独立提交。

## 四、仓库检查

```bash
git status
git log --oneline --decorate --graph
```

确认：

- 没有未提交修改。
- 没有 `.env` 或密钥。
- `README.md` 包含项目介绍、技术架构、安装运行指南和团队信息。
- `.env.example` 与 `requirements-dev.txt` 已提交。
- `npm run check` 通过。
- 仓库可公开访问。
- `screenshots/`、`docs/`、`output/` 已提交。

GitHub 仓库公开或评审访问检查：

1. 使用无痕浏览器打开仓库地址。
2. 未登录状态能够查看源码、README 和提交历史。
3. 如仓库为 Private，已在提交平台提供评审账号或只读协作者权限。
4. Actions 运行结果可查看，且最新 `Project Check` 通过。
