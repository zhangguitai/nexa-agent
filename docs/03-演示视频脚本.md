## 二、逐段脚本

### 00:00 - 00:46 项目介绍

**画面**

- 深色品牌封面。
- 项目名称、赛题名称、产品定位与能力关键词。

**旁白**

> 大家好，欢迎观看 NEXA Agent Workspace 项目演示。NEXA 是一个面向知识工作者的 AI Agent 工作台。用户只需要描述目标，Agent 就会完成任务理解、自主规划、企业知识检索、工具调用和结果交付。项目面向传智杯 AI Web 网页开发挑战赛，重点展示大模型、智能体规划、工具调用、多轮对话和自动化工作流能力。

### 00:46 - 01:32 Agent 工作台

**画面**

- 工作台首屏。
- 任务命令输入、效率指标、Agent 团队、实时执行和自动化工坊。

**旁白**

> 首先是 Agent 工作台。顶部是任务入口，用户可以输入自然语言目标，也可以直接选择运营周报、竞品扫描、会议行动项等快捷任务。下方展示活跃 Agent、自动化任务、执行成功率和节省时间。智能体团队区域可以看到每个 Agent 的职责、运行次数和准确率。右侧实时执行面板展示当前任务进度，自动化工坊则把稳定的业务流程沉淀为可复用工作流。

### 01:33 - 02:19 智能对话与工具调用

**画面**

- 点击“生成运营周报”。
- 执行计划、工具调用轨迹、结果正文、知识来源和会话上下文。

**旁白**

> 现在演示智能对话。我们点击生成运营周报，Agent 会先展示执行计划，然后调用项目指标工具读取活跃团队、激活率和留存数据，并检索增长运营手册和客户反馈知识。最终结果包含关键指标、业务洞察、下周建议和后续任务。下方可以展开每个工具的调用记录，也能查看参考来源。用户还可以继续追问，例如调整建议优先级，Agent 会保留上下文完成第二轮回答。

### 02:20 - 03:02 可视化工作流

**画面**

- 六节点运营周报工作流。
- 节点配置检查器。
- 运行工作流与节点完成状态。

**旁白**

> 一次性任务可以通过对话完成，稳定流程则进入工作流。这条运营周报自动化包含六个节点：手动触发、任务规划、知识检索、质量校验、生成交付物和发送飞书。节点支持拖拽、缩放和配置，右侧可以设置模型、超时、失败重试和人工审核。点击运行后，每个节点按顺序推进，颜色和状态实时变化，执行日志同步记录节点名称、结果和耗时。

### 03:02 - 03:40 任务闭环与人工审核

**画面**

- 任务中心四阶段看板。
- 任务卡、执行进度和审核操作。

**旁白**

> 任务中心将 Agent 工作拆分为待处理、进行中、等待审核和已完成四个阶段。每张任务卡展示负责 Agent、负责人、截止时间和执行进度。涉及发送通知等关键动作时，任务会自动进入等待审核，人工确认后才继续。这样既保留自动化效率，也避免 AI 在未经确认时执行高风险写操作。

### 03:41 - 04:24 企业知识与工具连接

**画面**

- 知识库分类、检索、引用统计与文档详情。
- 飞书、企业微信、Notion、GitHub、Webhook 和 REST API 连接。

**旁白**

> 企业知识库为 Agent 提供可信事实。文档可以分类、检索、上传和解析，每条回答都能显示引用来源。在工具连接页面，可以管理飞书、企业微信、Notion、GitHub、Webhook 和自定义 REST API 的授权与启停。工具连接配置调用上限、写操作确认和返回内容记录，保证 Agent 的能力边界清晰可管理。

### 04:24 - 04:59 运行可观测性

**画面**

- 运行总数、成功率、平均耗时与异常数量。
- 展开执行轨迹与运行摘要。

**旁白**

> 运行记录展示总运行次数、成功率、平均耗时和异常数量。展开一次运行，可以看到完整的执行轨迹，每一步都有状态和耗时。如果工具调用失败，界面会直接定位失败阶段，并提供重新运行入口。这样 AI 的执行结果不再是黑盒，而是可以审计和持续优化的工程过程。

### 04:59 - 05:54 AI 技术方案

**画面**

- 大模型、Agent Gateway 和企业工具架构。
- Tool Calling 执行循环与代码接口示意。

**旁白**

> 技术方案方面，NEXA 使用 OpenAI 兼容的 Chat Completions 接口作为模型抽象层，可以接入 DeepSeek、OpenAI 或企业私有模型。用户消息和系统提示词进入模型，当模型返回 tool_calls 时，Node 服务端会执行白名单工具，再把结构化结果写回上下文。系统最多执行四轮工具调用，并设置超时、输入长度限制和错误降级。提示词要求涉及企业事实时必须调用工具，写操作必须由用户明确要求。

### 05:55 - 06:37 技术创新与应用创新

**画面**

- 过程可视化、对话与工作流统一、运行可观测、安全可控。

**旁白**

> NEXA 的创新点体现在三个方面。第一是 Agent 过程可视化，计划、工具、来源、状态和耗时都可以查看。第二是对话与工作流一体化，对话适合探索一次性任务，工作流适合稳定复用，任务中心负责人工审核。第三是真实模型与本地演示双模式，既保留大模型工具调用能力，也保证比赛现场在网络或模型异常时仍然可以完整展示。

### 06:38 - 07:20 总结

**画面**

- 移动端界面。
- 完整产品闭环、真实 Agent 能力与比赛现场稳定性。

**旁白**

> 最后总结，NEXA 不只回答一个问题，而是把目标转化为可规划、可执行、可审核、可追溯的工作结果。项目具备完整 Web 产品、真实模型接入、工具调用循环、工作流编排和自动化测试，同时适配桌面端和移动端。感谢各位评审观看，NEXA Team 期待在传智杯 AI Web 网页开发挑战赛中展示更多可能。

## 三、正式录音与替换音轨

1. 在安静房间使用普通话录制配音稿。
2. 建议语速为每分钟 210 至 230 字，保持与段落时间轴一致。
3. 在剪映、Premiere 或 DaVinci Resolve 中导入当前字幕版 MP4。
4. 将配音音轨与对应段落对齐；如有偏差，可微调画面时长。
5. 保留已经烧录的字幕；也可关闭烧录字幕，使用 SRT 文件重新生成。
6. 导出 H.264、1080p、30 FPS、AAC 音轨的最终 MP4。

## 四、录制检查清单

- 视频总时长在 5 至 8 分钟之间。
- 分辨率为 1920 × 1080 或更高。
- 普通话配音清晰，无明显环境噪声。
- 项目介绍、核心功能和 AI 技术亮点均覆盖。
- 字幕与语音内容一致。
- 页面中不出现 API Key、个人信息或无关通知。
- 结尾包含项目名称和团队信息。
